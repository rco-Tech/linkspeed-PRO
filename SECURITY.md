# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within LinkSpeed Pro, please report it privately to the maintainers rather than creating a public GitHub issue.

Please email the maintainers or use GitHub's private vulnerability reporting feature on the repository:
https://github.com/rco-Tech/linkspeed-PRO/security/advisories/new

We will review your report and respond promptly.
